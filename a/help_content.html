快速上手

本指南面向首次使用 DALI 上位机的调试和维护人员。按一次实际工作顺序组织：找到控制器，确认会话，选定总线与地址，执行控制或配置，再核对结果。标题中的 QS 编号是后续帮助页面的稳定章节标识；二级标题对应页面章节，三级标题对应可独立展开的段落。

界面可见的功能取决于控制器固件、当前会话、所选对象和设备能力。本文描述当前上位机已有的操作入口；涉及真实灯具、固件烧录和不同平台的操作，仍应以现场反馈为准。术语可跳转到 DALI术语。

QS-01 开始前：明确设备和影响范围

QS-01.1 准备控制器、总线和主机

准备受支持的自研 DALI 控制器、稳定供电、USB 数据线或可通信的局域网、DALI 总线电源和待调试的灯具驱动。由具备相应资质的人员确认总线接线、电源容量和现场用电安全。USB 接入还需确认系统设备权限；局域网接入需确认主机与控制器能互通。

本软件通过 USB/串口或局域网接入自研控制器，再由控制器访问其 DALI 总线。上位机的局域网连接是控制器传输方式，不能据此认定整套系统已经支持 DALI+。控制器与 DALI 灯具驱动是两种对象；控制器列表中的一台设备不等于一台灯具。

QS-01.2 先选现场，再选动作

对现场灯具的广播、分组、编址、参数写入和场景操作可能立即影响照明或改变设备配置。开始前确认目标控制器、总线、影响到的灯具及可接受的施工时段。首次熟悉界面可先完成连接、扫描和只读查询，再做单个短地址的基础控制。

QS-01.3 一条最短上手路径

  1. 启动软件，在欢迎页搜索并连接控制器。
  2. 进入工作台，核对控制器身份、连接会话和 DALI 总线。
  3. 扫描总线，选择一个有应答的短地址。
  4. 在实时控制中执行一次单灯开/关或亮度操作。
  5. 观察操作反馈，并在“信息 · 参数”或查询入口回读相关状态。

完成第 4 步只说明已发起操作；第 5 步用于确认控制器响应和设备实际状态。若现场灯具没有变化，转到 QS-09。

QS-02 发现并连接控制器

QS-02.1 从欢迎页搜索

欢迎页提供 USB/串口、局域网和全部设备的搜索路径。选择实际接线方式后等待结果；搜索不到时先查供电、线缆、权限、同网段或网络路由，不把无结果直接解释为 DALI 总线故障。当前正式进入工作台的路径要求本次启动发现并验证控制器，历史缓存不代表控制器当前在线。

QS-02.2 核对候选与实体

搜索结果中的“端点”是接入位置，例如一个串口或网络地址；同一控制器可能有不止一个端点。连接前优先核对产品身份、MAC、固件版本、传输方式和端点。仅靠显示名称或网络 IP 无法可靠判定是否为同一台实体。发现的候选数、已验证控制器数和已连接会话数是不同统计口径。

QS-02.3 建立并观察会话

选择有效控制器连接，等会话进入可操作状态后再执行总线命令。工作台中的控制器详情和检查器可查看连接、会话、能力与占用信息。已发现但未连接、连接中、握手中、会话就绪、挂起、重连中、超时或错误不能统称为“在线可控”。另一主机占用或能力未上报时，按钮可能保持禁用。

断线后先核对物理链路和占用状态，再使用重连。必要时断开当前会话并重新选择端点；不要把本次会话编号当成控制器的永久编号。

QS-03 认识工作台和目标层级

QS-03.1 仪表盘、工作台和工作模式

“仪表盘”用于汇总和进入功能，“工作台”用于围绕当前对象操作；顶部视图菜单也可切换主界面。“标准模式/现场模式”是工作模式，不是另一套控制器或总线。窄屏会把部分入口收进菜单，业务目标和操作结果仍以当前选中的对象为准。

QS-03.2 从对象树读取当前范围

工作台对象树按“连接与控制器 / 已连接控制器 → 控制器 → DALI 总线 → 广播或短地址”展开。左侧导航切换功能，中部呈现对象操作，右侧检查器显示身份、会话、能力和常用动作；手机布局将对象树与功能入口分步呈现。每次操作前先查看当前控制器、总线和目标标题，避免在切换页面后沿用上一个地址的判断。

“广播”只作用于当前选定总线中的相应设备，不是对所有控制器同时发送。短地址是该总线上控制装置的 0..63 地址；树中列表序号、组号和场景号都不是短地址。

QS-03.3 正确看待状态圆点和计数

树节点旁的圆点表示该节点自己的业务状态：父级可汇总连接情况，控制器节点表示会话，总线节点表示扫描，设备节点表示结果可信度。父子节点同时显示绿色不代表有两次连接。桌面端可悬停读取具体提示；触屏端结合节点文字、详情和状态面板判断。

“可用”“警告”“处理中”“错误”“离线”应结合所在节点解释。没有圆点或显示“未知”表示尚无足够证据，不能当作正常。状态栏的候选数、可用数和警告数也不等于总线上的灯具台数。

QS-04 扫描 DALI 总线并识别灯具

QS-04.1 执行一次扫描

  1. 在“已连接控制器”中选择目标控制器下的 DALI 总线，确认会话和扫描能力可用。
  2. 启动总线扫描，观察地址范围、进度和当前已识别数量；扫描期间不要同时对该总线执行互相干扰的配置任务。
  3. 等待终态，查看短地址列表。若取消、失败或结果不完整，先处理原因，再重新扫描形成新的结果。
  4. 选择短地址，进入设备信息或参数查询，核对类型、响应和可用能力。

当前扫描主要识别有应答的已分配短地址控制装置。它不能凭一次查询直接证明每个地址只有一台物理设备，也不能自动计入未编址设备或 DALI-2 传感器。一个短地址得到肯定应答，仍不等于已排除同址冲突。

QS-04.2 区分扫描的四类终态

终态 应如何使用结果
完成 该次扫描按计划结束；仍要结合应答与实际灯具核对唯一性和数量。
部分完成 可供排查的地址可能保留，但不可当作全线完整清单。
失败 查看总线、会话、超时或协议错误，再重新执行。
已取消 操作未完成；保留已观察信息只作线索。

“已识别短地址数”是本次有应答的不同地址数量；“上次编址分配数”是另一次任务的历史结果，不能相减推导未编址台数。地址变化后应重新扫描。

QS-04.3 先只读核对设备

选中短地址后，先读取状态、设备类型、当前电平及可用参数。设备类型或 DT8 色彩能力未读取到时保持“未知”，不要从商品名猜测。只读页面显示的是读取时刻的快照；切换目标后先确认标题和刷新结果，再解释值。

QS-05 完成第一次照明控制

QS-05.1 选择单灯、分组或广播目标

日常控制可选单个短地址、某一组或当前总线广播。首次操作优先选一个已验证响应的短地址；组和广播的影响范围更大。组是设备侧的成员关系，控制器部署资料中的“楼层/区域”和控制器集群都不会自动变成 DALI 组。

QS-05.2 执行控制并核对

在实时控制或检查器中按当前目标执行开灯、关灯、调亮、调暗或设定亮度。色温和其他颜色控制仅在目标设备类型、能力以及固件路径支持时使用。操作结束先看发送或事务反馈，再结合实际灯效与必要的状态查询验证。发送成功不保证灯具已经达到预期亮度；灯具故障、物理限值和外部控制都可能影响结果。

亮度控制值不是照度 lx，也不能简单当成灯具功率百分比。若当前目标显示“广播”，请再次确认总线；若显示短地址，请再次确认数字与实际灯具一致。

QS-06 在明确目标后修改配置

QS-06.1 编址与重新编址

未编址设备需要通过总线编址流程获得短地址。开始前区分“保留已有地址、仅处理未编址设备”与“对全部设备重新编址”；后者可能使既有组、场景和工程记录失去对应关系。阅读界面风险确认，观察作业进度、取消或失败终态，结束后重新扫描并逐项核对。

对已知短地址的日常改址，使用对象树或总线短地址表中的“重新编址”受控入口。清除短地址会使目标设备从普通短地址扫描列表中消失，需重新分配地址才能按地址访问；它不是恢复出厂设置。同址设备可能同时受到定向命令影响，扫描不能保证仅改动一台物理设备。协议工具中的裸命令只供专家联调，不作为完整改址流程。

QS-06.2 设置通用参数

“DALI 参数设置”面板覆盖渐变时间、扩展渐变时间、渐变速率、最大亮度、最小亮度、上电亮度和系统故障亮度。先确认目标是短地址、组还是广播，再选择要写入的项目、输入合法值并执行。移动滑块或编辑数字只是准备待发送值；写入后查看结果，对可查询的单个设备再做回读。组或广播写入要验证每个成员，不能由一次发送反馈推断全体成功。

渐变时间和扩展渐变时间不能作为两套有效设置同时提交。上电亮度中的 255 表示记忆亮度；系统故障亮度中的 255 表示维持当前亮度，二者含义不同。具体可用值和扩展渐变时间支持以当前面板与设备能力为准。

QS-06.3 配置组与场景

DALI 组号和场景号均为 0..15。先读取单设备的组成员关系，修改后看差异并回读；一个控制装置可以属于多个组。场景是各设备保存的同号槽位值，调用场景与存入场景是不同操作。设置组场景时按成员分别确认写入和回读；读取到 MASK/未存储 不应按有效亮度使用。组和场景的现场灯效仍需结合实际设备验收。

QS-06.4 查看高级设备能力

设备详情可按实际读到的能力展示 DT8 色彩和 D4i 数据等分区。色温 Tc、xy、RGBWAF 不是同一控制方式；只读数据存在不表示对应写入已经开放。D4i 的数据、供电和认证要求不能仅由一个设备类型编号推断；未经完整证据不要标记“D4i 设备”。传感器、按键及其事件处理属于后续 DALI-2 控制设备能力，不能用当前控制装置扫描结果代替。

QS-07 管理控制器资料与软件设置

QS-07.1 记录控制器部署信息

控制器个性化资料可记录名称、使用场景、场所、楼栋、楼层、区域、位置和备注。保存前核对稳定身份，保存后重新选中同一控制器确认内容。本地保存的是上位机资料；固件资料同步有独立的支持条件和结果。换机或清理应用数据前应备份需要保留的本地资料。

资料管理提供导出、导入预览和冲突处理。导入前确认控制器身份、覆盖字段和备份范围。个性化资料包不等于整条 DALI 总线的完整配置备份，也不能代替未来工程文件、批量恢复或报告功能。

QS-07.2 区分本地设置与控制器维护

语言、主题、字体和显示偏好属于本地软件设置；网络、固件和控制器存储属于控制器维护。操作前看清保存位置和当前设备，不能把更换主题当作修改硬件状态。维护入口可能因固件能力、连接方式和会话状态而不可用。

QS-08 理解反馈、日志与协议工具

QS-08.1 按证据层级判断结果

界面预览表示准备发送，事务发送完成表示控制器执行器已处理前向命令，查询应答表示设备返回了数据，写后回读及实际灯效才进一步证明配置或照明效果。任何一层都不能自动替代下一层。无应答可能是某些 YES/NO 查询的正常“否”，也可能由断线、错误目标或设备不支持造成；需结合具体命令判断。

QS-08.2 用日志定位问题

日志页用于查看操作、传输和错误线索。反馈问题时记录时间、控制器身份、连接方式、总线、短地址、动作、终态和固件版本；必要时导出日志。日志可能包含 MAC、端点和主机信息，分享前检查内容。当前日志不是原始 DALI 总线监视抓包，也不是工程备份。

QS-08.3 协议工具的适用人员

“协议工具”面向研发、联调和售后技术人员，按当前控制器与总线提供受控命令及预计帧、实际终态。首次上手使用正式的扫描、控制、参数、编址和组场景页面即可。协议工具显示的“预计 DALI 发送”不是实测波形；commandSent 不是灯具效果确认。需要用工具定位问题时参阅 短地址协议工具使用说明。

QS-09 常见问题与排查顺序

QS-09.1 找不到控制器或无法连接

先确认供电和数据线；USB 检查设备枚举及系统权限，局域网检查网卡、地址和可达性。再看搜索结果是候选、已验证实体还是已连接会话；占用、挂起、会话超时与身份校验失败有不同处理方式。连接问题未解决前，不进入 DALI 总线故障判断。

QS-09.2 能连接但无法扫描或按钮不可用

检查当前控制器和总线是否选定、会话是否可操作、固件是否报告相应能力、是否已有互斥作业进行。禁用或“未知”不是可通过反复点击消除的状态。若扫描中断，查看终态和完整性提示后重新执行。

QS-09.3 扫描数量与现场不符

先确定所看的是“已连接控制器”“已识别短地址”还是“上次编址分配数”。未编址、不应答、同址冲突、扫描取消或总线故障都可能使短地址结果与物理灯具台数不一致。现有扫描不能直接给出未编址台数、同址台数或超出地址上限的设备总数。

QS-09.4 命令已发送但灯未变化

依次确认目标地址与总线、控制器会话、设备应答、实际灯具和供电；再检查灯具故障、最小/最大电平、场景是否存储、组成员是否正确，以及外部主控是否同时操作。对写入动作读取对应参数，对亮度动作读取实际电平，必要时结合现场观察。

QS-09.5 信息显示为未知、未支持或不完整

“未知”表示缺少可靠数据，“未支持”表示当前能力或协议路径不可用，“不完整”表示任务或读取未形成完整结果。三者都不能改写成零值、关闭或成功。保留原始终态和日志，核对固件版本、目标设备能力及命令来源后再继续。

DALI术语

本词汇表按“标准与认证 → 系统角色 → 寻址与控制 → 帧和结果 → 设备类型与颜色 → 数据与 D4i → DALI-2 输入设备 → DALI+ → 本软件状态”的认知顺序编排。T 编号是稳定的内容标识：二级标题为页面章节，三级标题为可独立索引的术语条目；不要用术语在表格中的行号作页面锚点。中文名称优先采用 DALI Alliance 的推荐术语，英文保留在首次出现处，便于与证书、标准和协议命令对应。

“本软件”指当前 Flutter 上位机，不代表连接的任意控制器或设备都具备相同能力。术语是概念解释，不构成产品认证声明。官方网页会更新；本稿于 2026-11-10 核对 DALI Alliance 页面。具体标准版本和可认证的 Part 应以官方 DALI-2 Parts Available 与产品数据库当时记录为准。[S] 是官方资料，[P] 是本项目当前实现依据；文末列出完整来源。

T-01 标准、版本与认证

T-01-01 DALI

Digital Addressable Lighting Interface，数字可寻址照明接口：用于照明设备之间的双向数字通信，支持控制、配置和查询。DALI 既指通信技术，也常被用作行业统称；讨论正式标准时应写明 IEC 62386 分册，讨论产品资格时应写明实际认证项目。S2 S3

T-01-02 IEC 62386

规定 DALI 通信与设备要求的多部分国际标准。Part 101/102/103 分别覆盖系统、控制装置和控制设备的通用要求；设备特定功能由其他 Part 扩展。标准发布、DALI Alliance 的补充规范和某一 Part 是否已有认证测试是三种不同状态。S4 S12

T-01-03 DALI Alliance / DiiA

Digital Illumination Interface Alliance，DALI 联盟；DiiA 是其组织名称/缩写。联盟维护 DALI-2、D4i 等认证、测试流程、推荐术语与产品数据库；IEC 62386 由 IEC 发布。不能把“采用了 DALI 命令”自动表述为“获得联盟认证”。S0 S3

T-01-04 DALI version-1

早期 DALI 产品登记体系，范围限于控制装置；控制设备及总线电源不在其登记范围。与 DALI-2 的差别不只是通信速度或界面版本。官方已关闭新增 version-1 控制装置登记。S3

T-01-05 DALI-2

基于较新 DALI 规范的联盟认证项目，覆盖控制装置、控制设备和其他适用产品类别，强调经验证的互操作性。产品标注 DALI-2 应有对应认证和数据库记录；上位机能查询一台 DALI-2 设备，并不使上位机或自研控制器自动成为 DALI-2 认证产品。S3 S12

T-01-06 DiiA Specification

DALI 联盟发布的规范，补充 IEC 62386，包括 D4i 数据/电源相关 Part 和 DALI+ 的 Part 104 Changes & Additions。实现某份规范与该功能已可参加认证是不同结论，需查当期官方状态表。S4 S12

T-01-07 认证与互操作性

Certification / interoperability：认证针对具体产品及适用功能和标准版次，测试通过后可在联盟产品数据库核对。不同厂商产品共同运行还需符合部署条件；一次本地联调或某条命令有响应均不能代替认证。S3 S12

T-02 系统、总线与设备角色

T-02-01 DALI 总线 / 子网

DALI bus / subnet：传统有线 DALI 在同一对线缆上传送通信数据与总线电源。一个 DALI-2 子网最多有 64 个控制装置地址和 64 个控制设备地址，两类地址分别管理，不是共用一组“总共 64 台”的地址。实际可接入数量还受供电、电流预算、线缆和设备能力限制。S2 S5

本软件以“控制器 → DALI 总线”组织目标；当前固件发布的线路能力不能据此推断为多条实体总线。P1

T-02-02 总线电源（BPS）

Bus Power Supply：给 DALI 总线上的通信电路供电，可独立设置，也可集成在控制装置或控制设备中。常见标称约 16 V；总线最大供电电流约束为 250 mA，设计时须按设备保证供电电流和最大消耗电流核算，不能把“多接一个电源”当成无限扩容。S1 S5

T-02-03 控制装置（control gear）

通常直接控制光源输出的设备，典型实例是 LED 驱动器，也包括镇流器、转换器和继电器开关设备。Control gear 不是 DALI-2 control device。本软件当前短地址扫描主要生成此类对象，界面可能用“灯具驱动/电源”帮助识别。S1 S5 P1

T-02-04 LED 驱动器（driver）

控制 LED 光源的控制装置；“驱动器”是设备形态，“控制装置”是 DALI 协议角色。不要把驱动器与上位机连接的自研 DALI 控制器混称。灯具中可能还含有独立的传感器、控制设备和总线电源。S1 S5

T-02-05 控制设备（control device）

发送控制指令或提供输入信息的 DALI-2 设备，主要分为应用控制器和输入设备。它有区别于控制装置的寻址/分组语义，不能把传感器强行塞入现有的 Gear 短地址扫描结果。本软件当前仅预留模型与能力边界，传感器闭环尚未交付。S3 S5 P1

T-02-06 应用控制器（application controller）

使用输入、状态或外部系统信息作决定并向控制装置发命令的 DALI-2 控制设备。可为单主控或多主控；多主控场景需考虑事件与总线共享。它是DALI 总线上的协议角色，不等同于本软件通过 USB/LAN 接入的“自研控制器/网关”产品名称。S5 P1

T-02-07 输入设备（input device）

提供用户操作或环境信息的控制设备，包括按键、滑动/旋转输入、占用传感器和照度传感器。通常通过事件传递变化，也可轮询；是否能在本软件配置事件及绑定灯具，取决于未来控制设备与自动化功能的实际接入。S6 P1

T-02-08 灯具（luminaire）

完整的照明产品或安装单元，可包含一个或多个控制装置、光源、传感器和供电部件。一个扫描到的控制装置地址不能无条件等同于“现场一套灯具”；灯具资产信息与 DALI 总线地址也不是同一编号。S5 S7

T-02-09 本软件的控制器、端点与会话

Controller / endpoint / session：自研控制器是上位机连接的实体网关；端点是 USB/串口或网络接入位置；会话是一次有效通信上下文。同一实体可能有多个端点，IP 和会话 ID 都不是永久设备身份。此三词是本项目产品对象，不应与 IEC 的 application controller 混同。P1

T-02-10 有线总线的极性、拓扑与长度

联盟的系统资料说明传统 DALI 两线通信无须区分接线极性，可采用自由拓扑；所述典型两芯线缆条件下，最远设备间距离上限为 300 m。实际工程还要结合线径、电压降、总电流与现场规范校核，不能仅凭“300 m”判断可运行。S5

T-03 寻址、发现与配置范围

T-03-01 短地址（short address）

在一条 DALI 总线内标识单个协议目标的地址。控制装置的短地址为 0..63；DALI-2 控制设备也有独立地址域。扫描到一个有应答的短地址只能确认该地址收到过应答，不能证明没有两台设备共用该地址。S2 S3 P2

T-03-02 未编址设备（unaddressed device）

尚未分配短地址的设备，不会因普通短地址查询而出现在已识别地址清单中。未编址数量不能由“现场灯具数减去扫描地址数”可靠得出；需使用合适的编址和验证流程。P2

T-03-03 编址 / 调试投运（addressing / commissioning）

为设备分配可管理地址并核对响应的过程。保留已有地址、仅处理未编址设备与全量重新编址有不同影响。改址后应重新扫描，并核对组、场景和工程引用；写入命令发送完成并不证明新地址唯一。P2

T-03-04 随机地址（random address）

编址流程中用于搜索和区分设备的内部地址，不是用户日常控制使用的短地址，也不是商品序列号。运行编址相关命令可能改变设备侧随机地址，不能把它当作完全无副作用的“只读 ID”。P2

T-03-05 同址冲突（duplicate short address）

两台或多台物理设备使用同一个短地址，可能使单地址控制同时影响多台设备。普通扫描、一条肯定应答或一条总线错误都不足以给出同址物理台数或唯一性结论；需要专门的证据与实机验证。本软件尚未交付逐地址同址诊断闭环。P2

T-03-06 组（group）

DALI 逻辑控制目标，控制装置可属于 0..15 中的多个组。组成员资格保存在设备侧；组号不是楼栋区域、控制器集群或广播。改变成员关系后应逐台回读或核对灯效。S2 P2

T-03-07 场景（scene）

设备侧预存的 0..15 号照明状态槽位。一次“调用场景”命令可令不同设备调用各自同号槽位的预设电平/颜色；“存储场景”“移除场景”和“调用场景”是不同操作。当前项目的基础场景值读写以相应设备与协议能力为边界。S2 P2

T-03-08 广播（broadcast）

对当前 DALI 总线内相应设备共同寻址。它扩大当前命令目标范围，但不自动跨越多条总线或多台上位机控制器。现场执行广播参数写入前须确认作用范围；单次发送不能证明每个接收设备都已生效。S2 P1

T-03-09 MASK / 未存储

某些 DALI 配置和场景查询中的特殊值，表达未设置、忽略或保持的语义，含义须按具体命令判断。场景槽位回读为 0xFF 时，本项目显示 MASK/未存储，不把 255 当成有效亮度。P2

T-04 命令、数据寄存器与操作结果

T-04-01 前向帧与后向帧

Forward frame / backward frame。前向帧由控制侧发送命令或数据，后向帧是目标对查询的响应。有些 YES/NO 查询以无后向帧表达“否”；另一些查询无应答可能是错误，必须结合命令定义和会话/总线状态判断。P3

T-04-02 直接弧光功率控制（DAPC）

Direct Arc Power Control：按控制值请求目标达到相应光输出电平，是 DALI 基础调光路径。控制值不是实测光通量、功率百分比或环境照度；最小/最大电平、曲线和设备故障会影响效果。S2 P3

T-04-03 当前电平与亮度参数

Actual level / maximum level / minimum level。“当前电平”是查询得到的设备状态快照；最大/最小电平是配置边界。修改待设值、发送命令、读回值和实际灯效是不同证据阶段。本软件的“信息 · 参数”只读区与“DALI 参数设置”写入面板也应分开理解。P1 P3

T-04-04 渐变时间、扩展渐变时间与渐变速率

Fade time / extended fade time / fade rate：前两者描述到达目标电平的渐变时长配置，渐变速率描述步进调光速度；扩展渐变时间属于 DALI-2 后续能力。本软件面板限制普通与扩展渐变时间同时作为有效配置提交；扩展路径仍须看固件和设备支持。S3 P1

T-04-05 上电电平与系统故障电平

Power-on level / system-failure level：前者作用于上电后的亮度恢复，后者用于系统通信故障情形。本软件七项通用参数中都可配置，但相同的数值 255 具有不同语义：上电电平为记忆亮度，系统故障电平为维持当前亮度；不应解释成最高亮度。P1

T-04-06 DTR0 / DTR1 / DTR2

Data Transfer Register：设备的临时 8 位数据寄存器，供后续命令取参；它不是短地址，也不自动等于已写入的永久参数。16 位色彩值等会用多个 DTR 组合，顺序与意义随命令变化。联调时应核对 DTR 装载、目标命令及必要的重复发送要求。P3

T-04-07 查询（query）与回读（readback）

查询请求设备返回当前状态或参数；回读是写入后再次查询，以检查配置是否落在预期值。返回数据必须按目标、命令、时间和完整性解释；一次成功回读仍不能代替灯效或多成员逐台核对。S2 P3

T-04-08 发送完成、超时与总线错误

本软件协议工具中的 commandSent 表示控制器执行器已发送前向命令，不是设备已生效；backwardResponse 表示收到应答；responseTimeout 表示窗口内无后向帧；busError 表示总线/帧错误，不能单凭它判定同址。Memory Bank 聚合读取还应核对状态与返回字节数。P3

T-04-09 预计帧与实测总线帧

“预计 DALI 发送”是上位机根据所选命令推算的帧序列；Product/Bridge 返回值是控制器事务结果。二者都不是独立硬件总线监视器采集的实际波形。当前日志和协议工具不等于完整的原始 DALI Monitor。P3

T-05 控制装置类型、调光与颜色

T-05-01 设备类型（DT）

Device Type：IEC 62386 的特定控制装置功能类别，不能与控制设备的“输入设备类型”混用。设备可能报告多个功能或扩展能力；应以查询与适用 Part 为依据，不靠型号名推断。S1 S4 P1

T-05-02 DT1：自容式应急照明

对应 IEC 62386-202，电池在灯具内或邻近灯具；可支持功能测试、持续时间测试和状态报告。看到 DT1 不代表本软件已经提供法定巡检与报告工作流，部署仍须遵循当地应急照明法规。S1 S8

T-05-03 DT6：LED 控制装置

对应 IEC 62386-207，用于 LED 灯的控制装置。DT6 与 DT8 都是控制装置的设备类型；拥有 DT6 不能据此推断具备色温或 RGB 控制。S1 S4

T-05-04 DT8：颜色控制装置

对应 IEC 62386-209。DT8 可涉及 Tc、RGBWAF、xy 等颜色类型；报告 DT8 不意味着每一种颜色类型均实现。本软件须按设备读取到的类型和能力显示操作入口。S1 S9 P1

T-05-05 Tc / CCT / mirek

Tc 是 DT8 的可调白色色温类型；CCT 是相关色温概念，通常以 K 表达。DALI 的 Tc 指令使用 mirek（百万倒数开尔文，mirek = 1,000,000 / K）表示，不应把开尔文整数直接装入 DTR。设备的物理冷暖限值与可写工作限值还应分开核对。S9 P3

T-05-06 xy 色坐标

使用 CIE 1931 色度图上的 x,y 坐标选择颜色，属于 DT8 的另一颜色类型。坐标不是 RGB 三通道百分比；设备色域和精度决定可达到的实际颜色。本软件现有 DT8 查询/配置仅按已实现的能力与受控服务开放。S9 P1

T-05-07 RGBWAF

DT8 的多通道颜色类型：Red、Green、Blue、White、Amber、Free-colour，最多六个通道。它不保证每个产品都装有六种物理 LED；通道分配及支持情况需查询。不要将 RGBWAF 三通道命令与 Tc 或 xy 的数值单位混用。S9 P3

T-05-08 调光曲线（dimming curve）

控制值到光输出的映射。经 DALI-2 认证的控制装置须满足相关标准化调光曲线与测试要求；实际光感和设备物理最小值仍需以产品与现场为准。DT6 的对数/线性曲线选择是特定功能，不能推广到所有控制装置。S2 P3

T-05-09 DT19：集中供电应急照明

联盟推荐术语将 DT19 对应于 IEC 62386-220 的集中供电应急照明控制装置，与自带电池的 DT1 不同。两者都不能仅因设备类型可识别，就推断本软件已经提供对应的应急测试、维护计划和合规报告。S1 S8 P1

T-06 存储体、DALI Data 与 D4i

T-06-01 Memory Bank（存储体）

设备内部按 Bank 和 offset 组织可查询数据的空间，DALI Data 在规定 Bank 中以标准格式提供。读取 Bank 字节与理解字段含义是两步；必须检查有效性、版本、长度和目标支持情况。本软件协议工具提供受控的 Bank 读取，不开放通用 Bank 写入。S7 P3

T-06-02 DALI Data

用于灯具资料、能耗和诊断的标准化数据集合，主要关联 Part 251、252、253。它利用双向 DALI 通信提供设备侧数据；是否有某项值取决于设备实现，未读到不能填写零值。S7

T-06-03 Part 251：灯具资料

Luminaire Data / Memory Bank 1 Extension：描述灯具额定供电、光输出、色温、显色性等资产信息，可由灯具制造商写入驱动器。它是灯具资料，不等于上位机本地记录的“控制器位置/备注”。S7

T-06-04 Part 252：能耗数据

Energy Reporting：定义驱动器可报告的能量/功率相关数据，供监测和分析。读取数据不等于本软件已有长期曲线、计费级计量或能耗报告；这些需要采集周期、存储、单位和精度的独立验证。S7 P1

T-06-05 Part 253：诊断与维护

Diagnostics & Maintenance：定义用于维护的设备运行与故障数据。设备没有相应字段或查询失败时应保留未知/不支持状态，不能推断设备健康。本软件已形成部分只读解析，完整业务与实机验证仍有边界。S7 P1

T-06-06 Part 250：集成总线电源

Integrated Bus Power Supply：D4i LED 驱动器的总线供电相关要求。它描述驱动器集成的 DALI 总线电源，不能仅凭界面看到某个状态字段就认定该设备满足整个 D4i 认证组合。S10 P1

T-06-07 D4i

DALI-2 认证的扩展，面向具备标准数据和供电能力的智能灯具生态。D4i 驱动器要求 Part 251/252/253 和 Part 250；Part 150 辅助电源可选。D4i 不是一个新的 DT 编号，也不能由“读到一个 Memory Bank”推断通过认证；认证产品须查联盟数据库。S10 P1

T-06-08 Part 351 与 Zhaga-D4i

Part 351 定义灯具内/灯具上安装的 D4i 控制设备及其供电和优先级等要求；Zhaga-D4i 是与 Zhaga 接口相关的联合灯具认证。它们与本软件 USB/LAN 控制器资料管理不是同一功能。S10

T-07 DALI-2 输入设备、传感器与事件

T-07-01 Instance（实例）

同一个 DALI-2 输入设备可在一个控制设备地址下包含多个输入实例，例如占用传感实例加照度实例。实例用于区分同一产品内的输入功能，不能直接当作新的控制装置短地址。联盟传感器资料说明一个产品可有最多 32 个实例。S6

T-07-02 Event（事件）

输入设备报告状态变化或用户动作的消息，例如按键短按、占用变化或照度变化。应用控制器需要决定如何响应，事件本身不是灯具执行命令。未来接入时需区分事件来源、实例、类型、时序和绑定规则。S5 S6

T-07-03 Part 301：按键

DALI-2 输入设备类别，描述按下、释放、短按、长按、双击等事件。按键可以触发调光或场景逻辑，但事件到灯具命令的映射由应用控制器/系统配置完成。S6

T-07-04 Part 302：绝对输入

覆盖开关、档位、模拟输入、滑杆或旋钮等能报告位置/数值的输入装置。其事件值不自动等于 DALI 弧功率值；需要业务映射及范围校验。S6

T-07-05 Part 303：占用传感器

用于报告有人、无人、移动或无移动等状态/事件。占用传感器不直接保证灯会熄灭或点亮；延时、优先级和场景需由控制逻辑定义。当前上位机尚无正式的传感器事件绑定工作流。S6 P1

T-07-06 Part 304：照度传感器

用于测量并报告照度；可借助滞回或周期上报减少总线事件。照度（lx），是环境光测量，不是某个驱动器的亮度设置值。恒照度控制需要采样、目标值和应用控制器闭环，当前本软件未交付该自动化流程。S6 P1

T-07-07 Part 305 / Part 306

分别面向颜色传感器和通用传感器。联盟传感器页在本次核对时将二者列为规范开发中；发布和认证状态会变化，后续页面应从官方状态表更新，不能提前显示为本软件已支持。S6 S12

T-07-08 轮询与事件驱动

Polling / event-driven：轮询是控制侧主动查询，事件驱动是输入设备在变化时主动报告；传感器还可周期上报。DALI-2 输入设备通常使用事件驱动模式，多主控部署需要明确谁处理事件和如何避免重复动作。S6

T-08 DALI+ 与其他网络互联

T-08-01 DALI+

在无线或 IP 网络承载上使用 DALI 命令的体系，不是“DALI-2 的下一代版本号”。其规范关联 IEC 62386-104 及联盟的 Part 104 Changes & Additions；具体承载、桥接和认证范围应查当期官方资料。S11 S12

T-08-02 DALI+ with Thread

使用 Thread 低功耗 IP Mesh 作为承载的 DALI+ 方向。Thread 是承载网络，DALI 命令和对象语义仍属 DALI+；是否可认证及支持哪些设备以联盟当期发布的测试项目为准。S11

T-08-03 Bridge / DALI+ 桥

在 DALI+ 网络与传统有线 DALI 子网之间连接的系统构件。DALI+ 的桥是跨承载互联概念；本项目协议工具中的 DALI Bridge 事务是自研控制器 Host 与固件之间的命令封装，二者同名但层次不同。S11 P3

T-08-04 无线到 DALI 网关

Wireless-to-DALI gateway：在无线生态协议与有线 DALI 之间翻译的网关；与端到端使用 DALI 命令的 DALI+ 不同。使用 BLE、Wi-Fi 或以太网接入控制器，只说明存在网络链路，不足以判定属于 DALI+。S11

T-08-05 本软件的 USB/LAN 连接

上位机通过 USB CDC 或局域网向自研控制器发送 Product/Bridge 事务，再由控制器操作有线 DALI 总线。它是主机接入与网关转发路径，不是 DALI+ over IP 实现或 DALI+ 认证声明。P1 P3

T-09 本软件中的状态与证据用语

T-09-01 已发现、已连接与会话就绪

“已发现”只表示有接入候选；“已连接”表示物理/传输链路建立；“会话就绪”还要求业务握手和当前能力可用。选择目标时应同时检查控制器身份、会话和总线。候选端点数不可当成已连接实体数。P1

T-09-02 扫描完成、部分完成、失败、取消

这是一次扫描任务的四种终态。“部分完成”可能保留排查线索，但不应提供完整清单的承诺；失败和取消也不能被重新命名为零设备。可信结果还需事件流完整且无完整性问题。P2

T-09-03 未知、未支持与待验证

“未知”是没有可靠数据，“未支持”是当前设备/固件/协议路径不具备该能力，“待验证”是软件路径或候选协议已有基础但尚无目标固件与实机证据。三者不能合并为“关闭”“故障”或“已完成”。P1 P3

T-09-04 快照与缓存

快照是某次查询或扫描在特定控制器、总线、地址和时间点的结果；缓存是为显示和继续操作保存的已知资料。它们都不是持续实时测量，也不能在目标切换后作为新目标的当前值。重新扫描或回读应生成新的证据上下文。P1 P2

T-09-05 本地资料与设备侧配置

控制器名称、部署位置等可保存在上位机本地；DALI 短地址、组成员和场景槽位属于设备侧配置。完成本地资料保存，不等于已同步固件或写入灯具；导入控制器资料也不是整线配置恢复。P1
