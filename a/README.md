# DALI Control Platform showcase

更新时间：2026-11-21 CST

这是面向国际市场的静态产品展示页，独立于 `pkg_bi_dali/dali_web` 工程工作台。产品入口为 `index.html`，下载、隐私说明与关于产品页面分别为 `downloads.html`、`privacy.html`、`about.html`。页面共用配色与字体样式 `site-theme.css`、语言面板样式和偏好脚本 `site-preferences.js`；首页、信息页和下载页分别由 `app.js`、`info-pages.js`、`download-page.js` 渲染。四页最终对客文案以 `customer-copy.js` 修订层为准，其余基础及扩展资源位于 `product-copy.js`、`download-copy.js`、`locales.js`、`locales-expanded.js` 和 `info-pages-expanded.js`。

## 目录约定

根目录保留可直接部署的页面入口，避免改变现有官网 URL；`help.html` 保留原有的状态指示说明。`help_content.html` 是工作台“快速上手”和“DALI 术语”共用的帮助页面，来源是仓库 `doc/帮助文档/` 中的两份 Markdown，供线上和离线环境使用；该页面不加入主站、关于或隐私页面的导航。其余文件按用途分为以下几组：

- 页面入口：`index.html`、`downloads.html`、`about.html`、`privacy.html`、`help.html`、`help_content.html`
- 页面脚本：`app.js`、`info-pages.js`、`info-pages-expanded.js`、`download-page.js`、`download-copy.js`、`locales.js`、`locales-expanded.js`、`site-preferences.js`、`site-controls.js`、`product-copy.js`、`customer-copy.js`
- 页面样式：`styles.css`、`info-pages.css`、`downloads.css`、`language-panel.css`、`site-theme.css`
- 展示资源：`assets/screenshots/`
- 本地预览：`dev-server.mjs`、`package.json`

`help.html` 和 `help_content.html` 内嵌相同的偏好脚本、公共样式和帮助页语言/主题控件，保持单文件可用；公共部分由帮助内容生成任务同步，不手工维护副本。直接打开时采用全站相同的默认设置和已保存选择。该文件的状态说明对应工程对象树中的状态圆点，不是对外公开的产品功能导航。

工作台帮助以 `doc/帮助文档/快速上手.md` 和 `doc/帮助文档/DALI术语.md` 为本地副本的唯一可编辑正文。修改后使用项目内的帮助内容生成任务更新 `help_content.html`，并在发布前执行生成结果检查。线上内容可以独立更新，本地副本随软件版本更新。资源包含两个独立栏目、稳定章节目录和术语搜索。帮助界面控件支持全站 17 种语言，正文仍为简体中文；切换至其它语言时明确提示正文语言，正文与章节目录单独标记为简体中文，不将其误标为已翻译内容。

帮助页的页头和章节目录保持在内嵌帮助窗口的可视区域内，正文使用独立滚动容器；窄屏时目录改为正文上方的横向菜单，并保持可见。窗口滚轮后备滚动目标指向正文容器。目录点击定位章节，当前章节高亮；切换栏目或筛选术语时复位正文滚动位置。布局和交互统一在帮助内容生成任务中维护，不直接编辑生成的 HTML。

## 默认显示与偏好

六个入口统一采用以下规则：

- 首次进入且没有有效选择时，使用简体中文 `zh-Hans` 和清透亮色 `light`；浏览器语言与系统深浅色不自动改变该默认值。
- 首页、下载、关于、隐私、状态帮助与操作帮助共用一份语言和主题选择。语言切换后其它页面沿用相同选择；主题保留深色、石墨深色、清透亮色和天蓝亮色四种。
- 优先保留有效的 `dali-locale` 和 `dali-theme`；没有共享语言选择时迁移原有说明页或下载页的有效语言。站点更新不重置用户选择；原有页面专用语言键仅作为兼容镜像。
- 参数 `lang`（或 `locale`）与 `theme` 可显式指定当前页面，在进入页面时优先于保存值；仅打开链接不会覆盖保存值。用户通过控件主动切换后才保存新的选择。
- 启动脚本在页头加载，在样式应用前设置主题与语言；页面在末尾脚本完成本地化前暂不绘制英文回退文案，避免切页闪动。所有页面共用字体、正文基础字号、配色及主题按钮样式；浏览器后退恢复和其它同源标签页的设置变化也同步显示。
- 浏览器限制本地存储时，页面仍能打开并在当前页切换；跨页面记忆以浏览器允许保存为前提。以同源 HTTP 方式预览和部署可检查跨页记忆，单文件直接打开仅保证页面自身可用。

在当前目录运行 `npm test`，检查默认值、旧设置迁移、跨页共享、受限存储、链接参数、后退恢复和帮助单文件公共资源一致性。修改公共偏好、样式或帮助控件后，运行帮助内容生成任务并执行 `--check`，同步两个帮助页的内嵌副本。

## 帮助内容发布

官网帮助对应 `sunshine-power/sunshine-power.github.io` 仓库 `main` 分支下的 `a/help_content.html`，不是独立的 `a` 仓库。2026-11-20 已通过只读查询确认该路径和当前页面。本工程目录中的同名文件为待发布副本；修改本地文件不会自动更新 GitHub Pages。

仅更新帮助正文时，在本工程根目录运行 `dart pkg_bi_dali/tool/generate_help_content.dart`，再运行 `dart pkg_bi_dali/tool/generate_help_content.dart --check`。将生成的页面同步到站点仓库的 `a/help_content.html`，检查差异后按站点既有方式提交与部署。该帮助页面为单文件页面，不需要同步应用代码、内部图片归档或其他产品页面。

发布后核对线上正文、目录、搜索与滚动；必要时比较线上文件与本地文件的校验值以排除旧缓存。帮助正文的线上更新无需重新制作安装包；本地副本和应用界面提示随软件版本更新。

## 内容边界

“快速上手”“DALI 术语”和状态帮助等面向用户的内容，只说明操作步骤、界面含义、功能范围及公开的 DALI 行业知识。不得出现编程语言、开发框架、内部芯片或模组、私有通信封装、代码标识、任务与服务结构、研发或验收进度，也不得链接源码、内部设计或开发指南。界面中已有的连接与状态名称应使用普通用户能够理解的方式解释；DALI 标准中的专业术语保留其准确含义。审校覆盖 Markdown 正文、最终生成页面和对应界面提示；展示截图还需检查画面内文字，不能只修改图片说明。

页面以《DALI 控制器及配套上位机控制软件功能规格表 V1.0》和现阶段工程进度为依据。公开的当前流程限于控制器发现与管理、DALI 寻址、分组与场景、设备读取、按广播/组/单地址目标设置常用参数，以及受设备能力约束的调光与 DT8 色彩控制；Type-C、局域网接入和本地诊断用于现场工作。工程文件、快照、批量任务、报告、AI，以及六类设备形态的正式截图与交付状态仍须按后续版本确认。标准导向不代表获得认证，真实总线兼容性和性能应以验证结果为准。

网站当前提供 17 种界面语言，选择菜单不展示尚未提供的语种。首页的 `50+` 表达的是可按客户项目需求定制的语言覆盖目标，**不是当前已交付 50 种语言**。

页面聚焦客户可验证的产品能力、适用边界与后续路线；研发实现细节、未确认的性能指标和商业合作条件不进入公开文案。首页 AI 区标为“未来方向”，正文明确当前版本尚未开放；17 种语言的客户口吻修订集中在 `customer-copy.js`，修改相关页面时需同步检查最终覆盖后的文案及 HTML 回退文本。

## 可读性基线

- 普通辅助说明保持在 11–12px，标签与占位说明不低于 10px；纯装饰性编号除外。
- 多语言自然语言优先使用系统无衬线字体，避免等宽字体造成中文、希腊文、韩文和越南文笔画过细。
- 深色、清透亮色、天蓝亮色均提高次级文字对比度；语言面板的本地名称与解释性名称使用 13px / 11px 组合并加粗。

## 本地预览

该页不依赖构建工具或第三方 npm 包。推荐在当前目录执行：

```bash
npm run dev
```

默认访问 `http://127.0.0.1:4180/`。需要修改端口时可执行：

```bash
PORT=4181 npm run dev
```

需要从同一局域网的其他设备访问时，将监听地址显式设为所有本地网卡：

```bash
HOST=0.0.0.0 npm run dev
```

然后使用本机局域网 IP（例如 `http://172.16.135.183:4180/`）；若仍无法访问，还需检查系统防火墙及网络隔离设置。

也可以使用 Python 启动：

```bash
python3 -m http.server 4180
```
